Backdrop images for the closing "tasaar" band on the homepage.

These are stars / galaxy photos that cycle behind the white wordmark.
Drop a wide, dark image (PNG) for each slot, named exactly:
  telecom.png   (provided)
  iiot.png
  energy.png
  ai.png
  industry.png

Any slot without a file shows a deep-space gradient until its image lands.
To add more frames to the loop, drop the file here and add a matching row
to the DOMAINS list in components/DomainWordmark.js.

Guidance: wide (~1600x900+), genuinely dark backgrounds read best — the
white word sits on top, and a light scrim lifts it without hiding the stars.
